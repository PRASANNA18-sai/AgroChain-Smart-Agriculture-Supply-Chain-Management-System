# AgroChain – Smart Agriculture Supply Chain Management System

## Overview

AgroChain is a Smart Agriculture Supply Chain Management System designed to improve agricultural logistics, crop inventory management, transportation planning, and market analysis using Data Structures and Algorithms (DSA).

This repository contains three case studies developed as part of the DSA course, covering advanced tree structures, graph algorithms, shortest path algorithms, and sorting techniques.

---

## Case Study 1 (CO1)

### Crop Inventory Management using Tree Structures

Topics Covered:

* Binary Search Tree (BST)
* AVL Tree
* B-Tree
* B+ Tree

Features:

* Crop Lot insertion, search, and deletion
* Balanced inventory management using AVL Trees
* Agricultural record indexing using B-Trees
* Range-based crop retrieval using B+ Trees

---

## Case Study 2 (CO2)

### Agricultural Supply Network Analysis

Topics Covered:

* Segment Tree
* Fenwick Tree
* Breadth First Search (BFS)
* Depth First Search (DFS)
* Prim's Algorithm
* Kruskal's Algorithm

Features:

* Crop production analysis
* Cumulative production statistics
* Supply network connectivity analysis
* Minimum transportation cost optimization

## Case Study 3 (CO3)

### Smart Logistics and Market Optimization

Topics Covered:

* Dijkstra's Algorithm
* Bellman-Ford Algorithm
* Floyd-Warshall Algorithm
* Merge Sort
* Quick Sort

Features:

* Shortest delivery route computation
* Logistics network optimization
